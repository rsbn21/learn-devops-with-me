# 🚀 DevOps Learning Journey

Welcome to my DevOps learning repository!

This repository documents my journey of developing and strengthening my DevOps skills through hands-on practice, projects, challenges, and experimentation.

My goal is to build a strong practical understanding of DevOps technologies rather than simply learning the theory.

## 🛠️ Technologies & Tools

Throughout this journey, I will be working with:

* 🐧 **Linux** – Command line, permissions, processes, networking and system administration
* 🐚 **Bash** – Shell scripting and automation
* 🌿 **Git & GitHub** – Version control and collaborative workflows
* 🐳 **Docker** – Containers and application packaging
* ☸️ **Kubernetes** – Container orchestration
* 🏗️ **Terraform** – Infrastructure as Code
* ⚙️ **Ansible** – Configuration management and automation
* 🔄 **CI/CD** – Building automated deployment pipelines
* ☁️ **AWS** – Cloud infrastructure and services
* 📊 **Monitoring** – Observability, logging and infrastructure monitoring
