## Variables
Variables allow to store or manipulate data


- act like container for strings, numbers, arrays
- not constrained to a specific data type

Variables are created using assignment operator '='

e.g. name = Rubel

To call the variable 'name' -> you use $name


## Parameters
Parameters act as arguments that can be given to a script
- they are provided after a script name when executing a script
- they use special character $1, $2 etc, based on position
- $@ can be used to pass through all parameters
